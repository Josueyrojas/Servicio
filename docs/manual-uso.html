Guía de usuario

Trabajar con NOBAITC

NOBAITC es una aplicación de escritorio para generar fracciones factoriales mediante NONBPA y analizar la estructura de alias de una matriz experimental. Los cálculos se ejecutan en segundo plano; la interfaz muestra los resultados y los avisos de validación.

1. Iniciar y navegar

  • Versión distribuida: ejecuta dist-out/NOBAITC/NOBAITC.exe. Mantén completa la carpeta NOBAITC, que contiene el runtime de Java y los archivos necesarios.
  • Desde el código fuente: con Java 17 y Maven instalados, ejecuta mvn javafx:run desde la carpeta del proyecto.

Al iniciar se abre el módulo NONBPA. La barra superior permite cambiar entre NONBPA y Alias Structure. La opción Others aún no está disponible.

2. Generar fracciones NONBPA

  1. En Datos, configura los niveles de los factores. La pantalla comienza con dos factores; usa + y − para agregar o quitar factores. Cada factor necesita al menos 2 niveles.
  2. Revisa Información del Diseño y confirma que el diseño sea válido.
  3. Define el Tamaño de fracción (SF) dentro del intervalo permitido.
  4. Elige fracciones aleatorias o personalizadas y completa los datos que correspondan.
  5. Pulsa Generar Fracciones. Si la entrada o el diseño no son válidos, corrige los datos indicados por la aplicación.

Validaciones del diseño

ParámetroSignificado y condición
FactoresEntre 1 y 15 factores; cada uno debe tener nivel 2 o superior.
TRProducto de los niveles de todos los factores.
LCMMínimo común múltiplo de los niveles. El diseño requiere TR = LCM.
GLGrados de libertad calculados como número de factores + 2.
SF minEl mayor valor entre GL y el nivel más alto.
SFDebe cumplir SF min ≤ SF < TR.

Elegir fracciones

  • Aleatorias: indica cuántas generar. El inicio se elige al azar, sin repetición, entre 1 y TR.
  • Personalizadas: escribe los índices de inicio separados por comas o espacios, por ejemplo 1, 3, 5 o [1 3 5]. Cada índice debe estar entre 1 y TR. La lista determina cuántas fracciones se generan; el campo Número de fracciones no limita esta lista.

3. Consultar y exportar resultados

La pestaña Tablas presenta las fracciones generadas y sus métricas: inicio, matriz de datos, GBM, J2, GBM por factor, VIF y resumen de alias.

  • Haz doble clic en una fila para copiar la matriz al portapapeles y abrir los detalles.
  • Selecciona una fila y pulsa Copiar tabla para copiar el resumen y la matriz.
  • Pulsa EXCEL o PDF para elegir dónde guardar el reporte de resultados.
  • Selecciona una fila y pulsa Enviar a Alias para cargar esa matriz en el módulo de análisis.
  • Limpiar datos elimina los resultados y restablece el formulario.

4. Analizar una estructura de alias

En Alias Structure, introduce la matriz con una de estas dos modalidades:

Matrix

Define m (corridas o filas) y n (factores o columnas), completa las celdas y pulsa Calcular Alias. La cuadrícula admite hasta 120 filas y 120 columnas. Las celdas vacías se interpretan como 0; complétalas explícitamente para evitar resultados accidentales.

PlainText

Pega una fila por corrida. Separa las filas con punto y coma o saltos de línea; separa los valores con espacios o comas. Se permiten corchetes exteriores. Todas las filas deben tener la misma cantidad de valores. Para decimales, usa punto.

1 1 1
1 2 1
2 1 2
2 2 2

Pulsa Calcular Alias. El resultado indica las dimensiones, si el diseño es ortogonal o cuántos alias encontró, y muestra las relaciones entre efectos principales e interacciones. Para cálculos grandes puede aparecer una confirmación; elige continuar o cancelar. Limpiar borra la entrada y el resultado.

5. Solución de problemas

SituaciónQué revisar
Diseño no válidoComprueba que cada nivel sea al menos 2, que haya como máximo 15 factores y que TR = LCM.
Tamaño de fracción no válidoUsa un valor desde SF min hasta un valor estrictamente menor que TR.
Índice personalizado fuera de rangoVerifica que cada inicio esté entre 1 y TR.
Matriz de alias inválidaComprueba que no haya filas vacías y que todas tengan la misma cantidad de valores. En Matrix, verifica las dimensiones y las celdas.
El ejecutable no iniciaEjecuta el archivo EXE desde la carpeta completa NOBAITC extraída, no de forma aislada.

Consejo: al analizar datos pegados, revisa el número de valores por fila antes de calcular. En la cuadrícula, no dejes celdas vacías si no quieres que se interpreten como cero.
